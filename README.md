# Japanese Master (เว็บเกมจำลองข้อสอบ & สรุปเนื้อหาเตรียมสอบภาษาญี่ปุ่น)

เว็บแอปพลิเคชันเพื่อการทบทวนและฝึกทำข้อสอบภาษาญี่ปุ่น สกัดเนื้อหาจากเอกสารประกอบการเรียน 14 ชุด
(ตัวอักษรฮิรางานะ/คาตาคานะ, คันจิตัวเลข/วัน, คำศัพท์สิ่งของ/สถานที่/ราคา, ไวยากรณ์บทที่ 1-3)

## ฟีเจอร์หลัก
- **Exam Simulator (30 ข้อ):** จำลองข้อสอบเก็งจุดตาย พร้อมเฉลยละเอียด เทคนิคช่วยจำ และเสียงอ่านภาษาญี่ปุ่น
- **Flashcards 3D:** บัตรคำช่วยจำด้วยภาพและจินตภาพ สำหรับคันจิตัวเลข วัน และคำศัพท์สำคัญ
- **Speedrun Mode:** โหมดฝึกปฏิกิริยาตอบไว 5 วินาที
- **Cheat Sheet:** สรุปกฎเหล็กและข้อยกเว้นการอ่านเสียงเปลี่ยนที่มักออกสอบบ่อย

## วิธีเปิดใช้งาน
- เปิดไฟล์ `index.html` หรือ `japanese_exam_game.html` ด้วยเว็บเบราว์เซอร์ (Chrome / Edge / Safari) ได้ทันทีโดยไม่ต้องติดตั้งเซิร์ฟเวอร์
- สามารถเปิดใช้งานผ่าน GitHub Pages ได้โดยตั้งค่า source ไปที่ branch `main` หรือ `master`
